Combining design expertise and engineering experience to build the applications behind Point One's centimeter-level positioning platform, across customer-facing products and internal tools.

- **Partnered with design** on the creation of a UI library in Figma and recommended patterns and tokens aligned with ShadCN and Tailwind to expedite the development process and tighten the contract between engineering and design.
- **Developed a new design system** of React components using Base UI and semantic tokens for light and dark theme support, then published it to Point One's internal registry to power the business's applications, both external and internal.
- **Authored and published a Storybook** to document component usage and showcase common patterns and recipes for the design system.
- **Reorganized the product into a Turborepo monorepo** so packages could be isolated, tested, and shared across apps, and new applications could start on the same stack.
- **Prototyped device profiles for RTK corrections** with design and product, a configuration flow with no prior art, and carried it through implementation.
- **Migrated legacy Vite SPA to Next.js** using React Server Components for improved page rendering performance and rebuilt the UI to use the new design system component library.
- **Automated documentation** with GraphQL schema codegen and the Docusaurus framework so product and engineering docs stay in step with the codebase.
- **Built enterprise application features** for license management, device management, and role-based feature access.
- **Adopted spec-driven development with OpenSpec** so agentic work is validated against spec and verified in implementation.
